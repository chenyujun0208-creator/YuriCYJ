# Temporary reference assets

Reference: https://otato.art/

The scene and toy sprites are used in this local reference prototype at the user's request and are intended to be replaced with personal assets later. The source scene was cleaned with built-in image_gen to remove notes/signs on the board while keeping the shelf, desk composition, light and perspective.

Source asset URLs: /open/plate.webp and /open/sprites/{toy,robot,bot,duck}.webp with corresponding -shadow.webp files.
